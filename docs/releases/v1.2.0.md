# DocumentBasedHarness v1.2.0

本版补齐 Windows、Linux 与 macOS 的跨平台发现、字体测量和原生发布链。

## 主要变化

- Windows 自动发现 Chrome、Edge、Chromium、draw.io Desktop 和系统/用户字体。
- Linux 字体替代时使用保守的东亚文字宽度模型，减少 CJK 排版低估。
- skill 发现入口改为普通文件，不再要求 Windows 开发者模式或管理员符号链接权限。
- CI 覆盖 Windows、Linux、macOS；原生发布矩阵同时构建 x64 与 arm64。
- 发布前自动拒绝非公开样例 `runs/**` 和真实用户绝对路径。

## 下载选择

- `windows-x64` / `windows-arm64`：Windows 免 Python ZIP。
- `linux-x64` / `linux-arm64`：Linux 免 Python tar.gz。
- `macos-x64` / `macos-arm64`：macOS 免 Python tar.gz。

各原生包均在对应 GitHub runner 上完成完整测试、构建和 CLI 冒烟。draw.io 图形导出和
Chromium 图标栅格化仍是可选的外部能力，具体边界见 `docs/platform-support.md`。
