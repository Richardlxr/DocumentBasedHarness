# DocumentBasedHarness v1.3.0

本版改善科研与通用汇报的关系表达、阅读顺序和后续编辑，并修复渲染及发行验证缺口。

## 展示与编辑

- 新增证据驱动的原生 PPTX 对照表，支持文本引用、数值引用和列宽权重；HTML 同步输出表格。
- Mermaid 流程图支持子集默认生成可编辑的 PPTX 节点、线段和标签，HTML 使用内联 SVG；
  这两条路径无需 draw.io。报告图示导出仍需要 draw.io Desktop。
- 新增全宽与两至三栏内容布局，检查不支持的组合，避免静默丢失内容。
- 学术展示指令强调正文阅读路径、图文邻接和机制解释；连续纯文字页提示复查证据，
  不强制加装饰图，也不强制所有标题写成结论断言。
- 渲染记录包含原生对象清单和大面积图片提示；默认可编辑不等于跨播放器外观一致。

## 可靠性

- 补齐表格的证据依赖、图表标题及图示标签的可见数字检查。
- 修复暗色图示标签、双向箭头和 4:3 模板中的表格尺寸；检查模板缩放后的图示字号。
- HTML 布局检查逐页测量并覆盖表格，减少隐藏页漏检和嵌套容器误报。
- 首次渲染失败保留可读错误和失败凭据；冻结程序参与构建新鲜度检查。
- 六平台发行包均在解压后用合成夹具走实际 CLI 渲染，验证 PPTX、HTML 和带公式的 DOCX，
  并包含依赖元数据。

## 使用边界

支持 Windows、Linux、macOS 的 x64 / arm64 原生包；下载后可用 SHA256SUMS.txt 校验。
流程图为受支持的 Mermaid 子集，不支持任意 draw.io 无损导入；连线不承诺自动重路由。
字号或布局放不下时请简化或拆页。Office/WPS/Keynote 的最终视觉效果仍需实际检查。

详见仓库的 `docs/reviews/2026-09-08-release-audit.md`、`docs/platform-support.md` 和
`comh/instructions/references/research-presentations.md`。
