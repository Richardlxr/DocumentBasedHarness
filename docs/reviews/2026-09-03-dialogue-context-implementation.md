# 对话流程与上下文修复记录

本轮落实 [评估方案](2026-09-03-dialogue-context-assessment.md) 的便携 CLI 协议、
大纲与可选精修、渐进式指令和上下文恢复。未实现独立宿主授权服务，也未声称测得真实 agent 遵循率。

## 工作流程

```text
轻量 intake：目标草案、材料范围、已有用户依据、协作方式
  ↓
按目标提取证据，记录已读/部分读/未读范围及缺口
  ↓
沟通契约：已知要求、推断、建议默认、待定项 → 展示 → 用户接受
  ↓
论断、证据状态、反证与未知处置 → 媒介无关故事线 → 展示 → 用户接受
  ↓
按所选媒介生成粗大纲 → 展示 → 用户接受或明确委托
  ↓
关键节点模式：自主细化
共同打磨模式：逐页/节，从职责到要点、证据、细节 → 各单元接受或委托
委托模式：在已记录范围内连续细化
  ↓
正文与视觉 → 正式渲染 → 机械检查 + 判断型审稿 + 实际读者输出
  ↓
展示成品 → 当前用户验收 → 记录交付
```

用户已有答案直接采用；材料能查清的自行核验；只询问会影响当前决定的未知。
每项契约需要明确处置，不要求每项都单独问一遍。用户可随时改变精修档位。

## 已实现的检查

| 问题 | 现在的行为 |
|---|---|
| agent 裸调用 confirm 就继续 | 先 present 生成请求，再 respond 记录针对当前版本的实际回复及来源 |
| 契约漏项、推断冒充用户要求 | alignment 检查逐字段的来源、状态、依据与实际值；关键未答项阻止接受 |
| 问题被换阶段遗忘 | intake 问题带入后续；延期必须有理由及截止阶段，到期重新检查 |
| 未知论断直接讲成结论 | partial/assumption/needs_research 及自定义存疑状态需限缩边界或删除处置 |
| 故事线未确认就写大纲 | 保存投影前必须有有效故事决策；委托细化不能跳过故事接受 |
| 一次写完整套才给用户看 | 粗大纲来自计划结构字段；共同打磨逐页/节对齐，正式渲染/正文保存检查其完成状态 |
| 仅补样式也重复问结构 | 大纲只绑定结构、上游、来源与决策依据；页内细化和纯主题变化保留粗大纲确认 |
| 把样张当成品 | draft 禁止正式产出；deck 的 --preview 写入 .workspace，不产生正式构建凭据 |
| 旧回复确认了新内容 | 请求绑定 run、视图、上游、来源、coverage、intake、父决策；核心 Gate 也绑定文件字节 |
| 上游修改后旧待办卡住 | 新展示将已过期的待回复请求保留为 superseded；仍有效的其他待办不能被覆盖 |
| 恢复时直接继续写 | next 从同一状态计算 save/present/await_user/refine/render/review/deliver；context 恢复当前约束和待办 |
| 局部修复只看到支持证据 | evidence-pack 带 counterevidence；context 同时保留全局契约、故事骨架与关键未知 |
| 长历史丢掉拒绝意见 | 近期决策摘要外另保留旧拒绝意见；完整历史路径可查；超预算显式失败，不静默删硬约束 |
| 勾选读者测试却无结果 | review 必须引用实际输出及执行信息，保存输出哈希；输出变化会使验收失效 |
| 重试重复落验收记录 | 相同回复幂等；相同当前交付及备注重复执行不新增记录 |

## 入口与安装

- `comh/instructions/` 是指令唯一源，wheel 包含 14 份 Markdown 资源。
- 根目录 `skill/`、`stages/`、`references/` 为兼容链接。
- `.agents/skills/communication-harness` 提供仓库发现入口；独立安装的宿主需自行注册入口。
- `comh instructions <stage|skill>` 不依赖 run；`next` / `context` 按当前任务加载。
- `context --stage deck --node P01` 返回当前单元与全局约束；默认字符预算为 24,000，
  超出时要求增加预算或缩小单元，不假称 tokenizer 的 token 预算。

## 迁移与边界

旧 run 不改写历史：缺少请求依据的 Gate 保留为 legacy，不视为当前有效。
补 intake、coverage、alignment 后，逐层展示当前版本、记录真实回复、大纲对齐、重新审稿与验收。
样例 run 同样适用，未自动填入任何虚构同意。

CLI 记录是 agent_attested。代码可验证顺序、版本、字段和文件，但不能认证回复来自真人、
证明材料确实读完、证明独立审阅，或判断模型是否真正理解。任意 shell 写权限也不是授权隔离。
更强保证需要宿主独立接收用户事件，并限制生成 agent 修改决策状态的权限。
上下文包不能删除宿主已有消息或决定其压缩行为。真实 agent 轨迹评测尚未执行；
后续按评估文档中的固定场景检验跳步、漏问、重复提问、恢复和内容质量。
