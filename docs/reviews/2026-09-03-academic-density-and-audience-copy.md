## 内容预设与沟通位置

`brief.presentation.setting` 在 Gate 1 记录场合并纳入已有 alignment。academic 默认
`academic-rich`，general 默认 `balanced`；用户明确选择的 profile 和 overrides 优先。
不根据“学术腔”推断密度，不解释开放的 `spec.dimensions`；agent 将已有明确要求落实到
受支持的配置。与沟通契约一起确认，不新增独立审批。

`academic-rich` 为文本型正文页提供约 300–550 个可见非空白字符、2–4 个主体分区的参考，
也提供独立英文词数范围。`balanced`、`concise` 及自定义范围供所有场合选择。
主图页可少字，封面/目录/分节/结尾/附录不套正文范围；草拟大纲不做成稿字数检查。
检查仅产生提示，不要求凑字、补造证据、增加无关主题或缩字。范围不保证每种版式都放得下。

配置由包内 JSON 提供，`comh presentation-profiles` 可查询；投影和演示稿细化的 context
返回实际生效配置及受众规则，narrative context 不带密度/布局字段。完整的任意布局模板
编译没有在此次实现，模板样式仍由 appearance 独立管理。

## 文案问题与限制

根因是把内部策划理由当作成品内容，以及把验证与限制压缩成难以理解的标签。
只增加“禁止废话”的提示无法可靠拦截；现在采用具体写作规则、已知模式检查和逐页语义 QA。

参考稿原生文字产生 3 个 error、3 个 warning：

| 位置 | 表述 | 处理 |
|---|---|---|
| 第 4 页 | 前置门槛：先立住工具，结论才有意义 | 空标签，阻断 |
| 第 4 页 | 机制层结论：Arm MPAM 方向研究的直接产出 | 空标签，阻断 |
| 第 4 页 | 应用层结论：委托方最终关心的价值 | 内部受众策划话术，阻断 |
| 第 13 页 | 可信性收口 | 抽象背书，提示审阅 |
| 第 13 页 | 适用边界后串联多项术语 | 提示展开条件与限制 |
| 第 13 页 | 确定性自洽、语义验证通过 | 提示说明具体检查及不能证明的部分 |

例如“委托方最终关心的价值”可改为实际研究问题“隔离后，控制周期的时延与波动改善多少？”
“可复现”应与“模型是否符合真实设备”分开判断。改写方向不是对参考稿结论的事实背书，
使用时仍需本 run 的证据支持；真实限制不能为通过检查而删除。

检查覆盖 narrative 的 message/statement、deck 的标题/页眉/要点/卡片标签/图注/
图表系列标签/支持的 Mermaid 标签，以及报告正文/标题/表格。内部 notes、purpose、
visual.intent、demotions 不进入成品文案扫描。实体编码残留阻断，较长同页重复提示审阅。
泛称“甲方”“结论”“适用边界”不禁用；专业术语不等于错误。

明确受众话术不受 voice.relax 豁免。用户确需引用反例时，可在契约中登记绑定位置、原文、
规则和真实用户依据的精确例外；不是授权系统，也不能由 agent 凭空填写例外。
正则不能证明全部文案有意义，图片内文字、复杂图形、跨页解释及受众适合度仍需语义/视觉 QA。
