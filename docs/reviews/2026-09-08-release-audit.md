# v1.3.0 发布审查与展示能力评估

日期：2026-09-08。审查基于 v1.2.0 后 main 的跨平台修复，以及本次学术展示改动。
覆盖工作流契约、证据和引用、作者指令、Schema、PPTX/HTML/DOCX 渲染边界、模板适配、
QA、构建凭据、独立打包、CI 和发布隐私。采用代码审查、合成回归和解压包真实 CLI 渲染。
这不是所有输入组合的形式化证明，也不是所有 Office 播放器的视觉认证。

## 总体判断

原有分层与版本确认机制适合保留。主要不足是“受众导向”更多落在文案和醒目标题，
未充分落实为证据载体选择、正文阅读顺序和交付后的编辑能力。仅增加文字密度或要求
每页有图都不能解决问题：应先识别观众要理解的比较、机制、条件与结果，再选择载体。

本次发现的确定性缺陷已修复，并加入相应回归。不存在目前已知但被忽略的发布阻断项；
正式发布仍须由 CI 的测试、隐私检查和六平台解压渲染检查全部成功后自动执行。

## 发现、修复与验证

| 问题 | 影响与修复 | 验证 |
|---|---|---|
| 长篇文字缺少关系表达 | 新增原生对照表、连续分栏；连续文本页提示人工复查证据，不规定装饰图配额 | Schema、结构组合、内容保留与渲染回归 |
| 标题醒目但正文阅读路径不明确 | 投影和 QA 指令要求检查首个注视点、阅读顺序、比较对齐、解释邻接；允许机制页使用主题标题 | 指令与阶段衔接审查；理解效果仍需真实读者 |
| 流程图导出为整张图片 | 支持子集直接生成原生 PPTX 节点、线段、标签；HTML 使用同一布局的 SVG | 编辑节点、表格后保存重开；动画目标完整性 |
| 表格证据未加入依赖包 | 单元格 evidence/value_from 纳入直接及派生证据链 | evidence pack 包含直接引用和传递依赖 |
| 可见数字检查有遗漏 | 表格文案、图示标签、图表标题纳入可见文本和数字检查 | 可见字段、数字和硬约束回归 |
| 暗色背景标签对比不足、双向箭头丢失 | 保留标签背景和双端箭头；SVG 同步 | 深色主题、箭头 OOXML/SVG 回归 |
| 4:3 模板只缩放表格外框 | 同步缩放行高、列宽和单元格边距；落地后检查图示最小字号 | 16:9 / 4:3 表格行列与外框一致，保存重开；小字号阻止发布输出 |
| HTML 隐藏页与表格溢出可能漏检 | 用独立区域逐页测量，不消耗出场步骤；纳入表格，排除父子容器的伪重叠 | 浏览器回归：封面正常、后续页长表溢出 |
| 首次渲染失败时输出尚不存在 | 保留原始错误、失败 QA 与失败构建凭据，避免哈希不存在的文件掩盖原因 | CLI 失败码、未发布状态和凭据拒绝 |
| 冻结程序无法只靠源文件追踪引擎变化 | 构建快照加入冻结可执行文件哈希；打包递归包含依赖元数据 | 解压后走实际版本确认与渲染链 |
| 发行冒烟只证明启动成功 | 每个平台解压正式压缩包，再生成 PPTX 表格/图示、HTML SVG、DOCX 公式 | 合成夹具走 CLI 保存、确认、渲染和全量校验；不冒充用户验收 |

## 保持的约束

- narrative 保持媒介无关；布局字段位于 deck_plan，视觉实现位于 renderer。
- 未支持的结构组合或放不下的内容明确失败，不静默丢内容、不截图整页兜底。
- 实测值和派生值先入证据；可见数字规则不替代语义审查，也不证明来源真实。
- brief/narrative/outline/appearance、协作节点、当前输出审阅和交付验收仍按各自范围执行。
  工程测试中的回复明确标注为合成夹具，不是真实用户授权或成品接受。
- 非公开 runs、用户绝对路径、原始对话、研究文件和本地具体案例分析不进入本次发行。

## 后续建议（不作为本版发布阻断）

1. **建立人工接受的展示回归集。** 覆盖组会、论文答辩、项目评审、通用决策汇报；保存
   初稿、修改要求、最终接受版本与原因。衡量关键关系是否看懂、寻找证据所需操作、
   修改内容能否完成，避免用图形数量、字数或单一美观评分替代理解。
2. **给作者提供关系驱动的页面范例。** 优先补充“实验条件—观测—解释”“基线对照”
   “机制—边界”等范例；容许不同研究内容使用不同结构，不把三栏作为新模板答案。
3. **建立播放器与字体的视觉矩阵。** 在实际 Office、WPS、Keynote、LibreOffice 中
   使用同一组文件验证换行、图表、表格和动画。现有自动几何诊断与原生对象清单只能
   提前发现风险，不能宣布跨播放器外观一致。
4. **扩展图形编辑语义。** 当前线段可以编辑，但不承诺拖动节点后自动重路由；任意
   draw.io 导入、复杂 Mermaid 图种及整套内容布局模板仍需独立设计、验收和回归。
5. **补充演讲模式与阅读模式的协同评估。** 现场观看的主次、渐进揭示与事后查阅需要
   分开验证；重要条件和限制不能只藏在备注中。

## 复现入口

- `pytest`：编译器、运行时、门禁、证据、渲染与展示回归。
- `ruff check . --no-cache`：静态检查。
- `python scripts/check_release_privacy.py`：被跟踪文件的发布隐私检查。
- `python scripts/build_standalone.py --output release`：构建、压缩、解压、实际渲染冒烟。
- GitHub Actions：九组跨平台/Python 回归；六平台原生构建成功后发布。
